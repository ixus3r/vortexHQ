> **This is the public product and community repository for Vortex.** It contains guides, feature highlights and feedback templates. The desktop application and backend are closed source; their source code is not published here.

## Why Vortex?

A coding conversation is only one part of building something. You also need the project files, the running app, its data and the services behind it.

Vortex brings that work together. Keep several conversations open, choose an agent for each task, review changes and try your app without losing the context of what you are making.

## What you can do

| Work | What Vortex brings together |
| --- | --- |
| **Build with AI agents** | Use your own accounts with Codex, Claude Code, Cursor, OpenCode, Google Antigravity, Grok Build, Kimi Code or Muse Code. |
| **Coordinate several tasks** | Organize projects and chats into workspaces, work side by side and follow linked tasks. Choose a separate Git worktree when you want isolation. |
| **Design and preview** | Review a design before building, keep your app beside the conversation and inspect the result in the embedded browser. |
| **Review your changes** | Browse files, inspect diffs and work with Git before deciding what to keep or publish. |
| **Work with databases** | Browse data, explore schemas and run queries against PostgreSQL, MySQL, MariaDB and SQLite. |
| **Test APIs** | Keep requests, collections, environments, scripts, tests and responses together. |
| **Reach your servers** | Use SSH, terminals and FTP, FTPS or SFTP alongside the project. |
| **Inspect mail and events** | Capture test email and investigate application events with Mail and Signals. |
| **Create with AI** | Generate images, video and audio with supported providers and models; keep references and versions together. |
| **Make it your workspace** | Add skills, project instructions, MCP tools and local scheduled tasks. Inspect running work in Resource Manager. |

## Get started

1. [Download Vortex](https://vortexhq.dev/#download) for your computer.
2. Open the app and connect your own coding-agent account.
3. Open an existing project folder or start a new project.
4. Describe a small task, review the result and try it in Preview.

Follow the [first-app walkthrough](https://vortexhq.dev/docs/getting-started-vortex), or start with the [Codex guide](https://vortexhq.dev/docs/connect-codex) or [Claude Code guide](https://vortexhq.dev/docs/connect-claude-code).

**Vortex is free to use.** AI provider subscriptions and usage charges are separate. Available models, generation inputs and usage limits depend on your connected provider. See [usage and storage](https://vortexhq.dev/docs/free-pro-and-resource-counting).
